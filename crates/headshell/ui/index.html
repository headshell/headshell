          plugins
          
            
          
              Written in JavaScript and run in the engine inside the app; you do not need to
              install any runtime.
            
          
          
          

          
          
            
            
            
            
          
          

          
          
            
          
              
              
            
          
            
          
              Permissions are not enforced. The listed permissions are the ones the plugin declares
              — the core does not technically restrict them (D-040). Consent is given to
              plugins you trust.
            
          
            
          
              Permissions are enforced. The plugin can only connect to the hosts it declares
              and cannot access the file system (D-069). The tools on the engine line
              (like yt-dlp) are separate programs and are outside this boundary.
            
          
            
            
            
            
              No plugins installed. You can install them from the catalog. A plugin installed by hand
              goes into the plugins/ folder of the data directory; its path is in the environment block under
              diagnostics.
            
            
          
            

          
            
            
            
              Plugins come from the headshell/plugins repository. The catalog is only read when you
              ask; every file is verified with its sha256, and an installed plugin awaits
              consent. An update never overwrites a plugin installed or changed
              by hand.
            
            
            
            
              
              
              
            
            
            
            
            
              
          
              

          
              
            
              
              Keys used by the plugins and the core (API keys, tokens, cookies).
              The list only carries names — values are never read back (D-042).
              The namespace is the plugin's name (ytmusic) or a link of the core
              (identity:acoustid).

                writing a theme
                
          
                
            A theme is a directory with theme.json and theme.css in it. Put it in the path
            below and press refresh the list — no need to close the app. The
            guaranteed surface is only :root and its --headshell-* tokens; themes that go
            beyond it are loaded, but flagged extended in the list.

                      1. 
                1
                
                  Set up a music source.
                  Local directories are set with HEADSHELL_MUSIC_DIRS and a remote
                  library (Subsonic, Jellyfin) is added under providers; for SoundCloud or
                  YouTube Music, install a plugin from the catalog.
                
                
                  
                  
                
              
                        2. 
              
                      2. 
                2
                
                  Import your history.
                  An export archive fills the statistics and the sleeve card. Today
                  Spotify's export can be read.
                
                
                  
                
              
                        3. 
              
                      3. 
                3
                
                  Play.
                  Type an artist or a track in the box above and press Enter; to queue every
                  matching track, press Shift+Enter.
