        sources
        
            
        
              Where your music lives — folders on this computer and your own music servers.
            
        
            
        Providers: where the sound comes from. They all play into the same queue, and every play is written to the same history.
        
            
        
              
              
            
        
          
        

          
          
        
            
        search here first
        
            
        
              When you search, we look here first — and only check your other sources if nothing
              turns up.
            
        
            
        The play box and its suggestions search here first; the others are asked only when nothing is found here, and their results are named (D-080).
        
            
        
              
            
        
            
        
          
        

          
          
        
            
        music folders
        
            
        Songs in these folders show up in your library.
        
            
          
            
          
            
          
              
            
          
            
          
              HEADSHELL_MUSIC_DIRS decides the folders for a run that sets it; with nothing
              chosen, the system's music folder is used. Files re-tagged in place are picked up by a
              plain scan.

          services
          
            
          
              Listen from YouTube Music, SoundCloud and more — add a service and it's ready to play.
            
          
            
          Plugins: written in JavaScript and run in the engine inside the app (QuickJS); you do not need to install any runtime.
          
          
          

          
          
            
            
            
            
          
          

          
          
            
          
              
              
            
          
            
          
              Heads up: only allow services you trust — they could connect to more than they
              say.
            
          
            
          
              A plugin reaches only the hosts it declares and none of your files (D-069); the tools it
              needs (like yt-dlp) run as separate programs.
            
          
            
            
            
            
              No services yet — have a look in browse for YouTube Music, SoundCloud and more.
            
            
            
            
              A plugin installed by hand goes into the plugins/ folder of the data directory.
            
            
          
            

          
            
            
            Find a service you like and add it in a click.
            
            
            
              Plugins come from the headshell/plugins repository (D-071). The catalog is only read
              when you ask; every file is verified with its sha256, and an installed plugin awaits consent.
              An update never overwrites a plugin installed or changed by hand.
            
            
            
            
              
              
              
            
            
            
            
            
              
          
              

          
              
            
              
              Some services need a key or a sign-in to work. Once you save one, it stays private —
              we never show it again.
            
              
            
              
              Keys used by the plugins and the core (API keys, tokens, cookies). The list only carries
              names — values are never read back (D-042). The namespace is the plugin's name
              (ytmusic) or a link of the core (identity:acoustid).

            writing a theme
            
                  
              A theme is a directory with theme.json and theme.css in it. Put it in the path
              below and press refresh the list — no need to close the app. The
              guaranteed surface is only :root and its --headshell-* tokens; themes that go
              beyond it are loaded, but flagged extended in the list.
